›_ ThreatLens API

REST API ile programatik olarak IOC sorgulama, tehdit analizi ve istatistik verilerine erişin.

🔑 Authentication

Tüm API isteklerinde X-API-Key header'ı gereklidir. API key'inizi profil sayfanızdan alabilirsiniz.

curl -H "X-API-Key: YOUR_API_KEY" \
    http://localhost:8000/api/search/?q=8.8.8.8
Rate Limit: 100 istek/gün
Endpoints
GET /api/search/?q={ioc}

IOC sorgula. IP, domain, URL, hash veya email kabul eder. Tüm entegre kaynaklardan veri toplar ve tehdit skoru hesaplar.

Parametreler:
q (zorunlu) Sorgulanacak IOC değeri
Örnek İstek:
GET /api/search/?q=8.8.8.8

GET /api/ioc/{uuid}/

Daha önce sorgulanan bir IOC'nin detay bilgilerini getirir. Yeni API çağrısı yapmaz, cache'deki veriyi döner.

GET /api/history/

Sorgu geçmişini listeler. Opsiyonel filtre parametreleri destekler.

type (opsiyonel) ip, domain, url, hash, email
page (opsiyonel) Sayfa numarası (varsayılan: 1)
GET /api/stats/

Genel istatistikler: toplam IOC, sorgu sayısı, tip dağılımı, severity dağılımı ve son sorgular.

GET /api/my-key/

API key bilgilerinizi ve günlük kullanım durumunuzu görüntüleyin.
